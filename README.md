# Portfolio (static)

A clean, modern portfolio website inspired by the provided reference screenshot.

## Run locally

You can open `index.html` directly in a browser, or serve it (recommended):

```bash
cd portfolio
python3 -m http.server 5173
```

Then open `http://localhost:5173`.

## Customize

- Edit text/links in `index.html`
- Tweak styling in `styles.css`
- Replace the hero image at `assets/reference.png` with your own photo
- Update the contact form email in `script.js` (`mailto:you@example.com`)
- Replace `resume.html` with your real resume (or link to a `resume.pdf`)
